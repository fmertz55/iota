# BioSystems submission checklist

## Machine-checked package

- [x] Full-length article type is stated in the manuscript.
- [x] Abstract is no longer than 250 words.
- [x] One to seven keywords are present.
- [x] Highlights contain three to five bullets of at most 85 characters each.
- [x] The manuscript contains no `\includegraphics` command.
- [x] All TeX inputs and the bibliography resolve inside the curated source ZIP.
- [x] Stable PDF and source ZIP have SHA-256 checksum files.
- [x] JSON build manifest records source, artifact, Git, and toolchain provenance.
- [x] Data/code availability, ethics, funding, competing-interest, CRediT, and
      AI-assistance statements are present.

## Author confirmation before upload

- [ ] Confirm the title, author name, affiliation, email, and corresponding-author role.
- [ ] Confirm every journal-facing file identifies IOTA as the information-first
      physics model and this manuscript as its artificial-life application.
- [ ] Confirm every numerical claim against the final evidence manifests.
- [ ] Confirm every reference and DOI against the cited primary source.
- [ ] Create an immutable repository release and DOI-backed archive; replace the
      current repository-only availability wording if the DOI is available.
- [ ] Tell the editor the current status of the related ICP manuscript and ensure
      neither manuscript presents the other as independent evidence.
- [ ] Reconfirm the competing-interest, funding, CRediT, and AI-use declarations.
- [ ] Upload the cover letter and highlights as separate journal files if requested.
- [ ] Inspect the journal-generated proof for equations, symbols, links, and line numbers.
- [ ] Record the exact submitted artifact hashes and submission date.
