
## Exact effective generator

Put

```text
q  = k delta,
mu = m delta,
n  = sqrt(1 - mu^2).
```

The momentum block can be written exactly as

```text

a   = n cos(q),
b_x = mu,
b_z = n sin(q).
```

The guarded production fixture also reconstructs this block from the
real-space recurrence using the fixed positive-sign target Fourier convention.
That cross-layer check caught and prospectively corrected the earlier reversed
edge orientation before any freeze or registered propagation.

Direct substitution gives

```text
a^2 + b_x^2 + b_z^2 = 1.
```

Let

```text
r     = sqrt(b_x^2 + b_z^2),
omega = atan2(r,a).
```

On the principal small-step branch,

```text
U_delta(k) = exp[-i omega (b_x sigma_x + b_z sigma_z) / r],

H_eff(k,delta)
  = (omega / (delta r)) (b_x sigma_x + b_z sigma_z).
```

The executable continuum fixtures require `|m delta|<1/4` and
`|k delta|<1/4`. This is a disclosed algebraic-log branch guard, not a
prospective registered domain.

## Small-step derivation

The ingredients through the required order are

```text
omega/r
  = 1 + (k^2 + m^2) delta^2 / 6 + O(delta^4),

b_x/delta
  = m,

b_z/delta
  = k - (k^3/6 + m^2 k/2) delta^2 + O(delta^4).
```

The `sigma_x` component is therefore

```text
m + m(k^2+m^2) delta^2/6 + O(delta^4),
```

and the `sigma_z` component is

```text
k - m^2 k delta^2/3 + O(delta^4).
```

Combining them yields the stated `K_2`. Equivalently,

```text
U_delta(k)
  = exp[-i delta H_D(k)] - i delta^3 K_2(k,m) + O(delta^4).
```

Thus the direct law agrees with one-step Dirac propagation through order
`delta^2`. Unlike the parent's product walk, this leading discrepancy is not
the commutator error of a sequential mass-mix/transport Lie--Trotter split.
It is the intrinsic correction generated by the direct normalized QCA law.

## Signed-step reversal and temporal meaning

Holding `k` and `m` fixed while reversing the signed step sends

```text
q -> -q,
mu -> -mu,
n -> n.
```

The exact block consequently obeys

```text
U_(-delta)(k) = U_delta(k)^dagger.
```

On the principal branch this gives

```text
H_eff(k,-delta) = H_eff(k,delta).
```

There is no term linear in `delta` in the effective generator. More generally,
its local expansion contains only even step corrections. The ordered local
updates supply an operational clock and a detectable finite-step signature,
but forward evolution is still exactly invertible when the complete quantum
information and inverse intervention are available.

Continuous Dirac time is therefore the effective description obtained when
the discrete local interaction step is unresolved. This audit does not claim
that the schedule itself emerged from a timeless construction: `delta` and
the gate order remain declared supplied structure.
