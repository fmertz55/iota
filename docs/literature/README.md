# Literature Search Records

Every new finding and gate specification requires a committed search record.
Copy the template below before outcome inspection and preserve its chronology.

## Required record

- finding or gate identifier;
- search status: pre-outcome, post-outcome, or update;
- search date and researcher;
- databases, indexes, and repositories searched;
- exact query strings;
- date and language limits;
- inclusion and exclusion criteria;
- mapping from project terms to common disciplinary terms;
- closest primary sources and why they are close;
- sources excluded after full-text inspection and why;
- effect on the proposed claim, method, or terminology;
- bibliography keys added; and
- unresolved coverage gaps.

Searches must use ordinary field terminology and cannot rely only on `IOTA`,
`ICP`, or other project-local names. Search snippets and secondary summaries are
discovery aids, not evidence; conclusions must be based on primary sources.
